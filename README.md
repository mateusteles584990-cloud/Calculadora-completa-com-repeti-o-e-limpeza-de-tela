🐍 Calculadora Completa com Repetição
Meu primeiro programa funcional em Python! O usuário digita dois números, escolhe a operação e o sistema calcula automaticamente. Limpa a tela a cada novo cálculo e repete quantas vezes quiser.
✅ Entrada e conversão de dados (input() + float())
✅ Condições múltiplas com if/elif
✅ Formatação de saída com f-strings
✅ Limpeza de tela compatível com Windows/Linux
✅ Loop de repetição contínua com while True
O começo de tudo! Cada linha escrita é um passo em direção a uma nova carreira! 💪
